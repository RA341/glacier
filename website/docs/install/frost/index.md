# Frost

**Frost** is the client component of the project.

You can think of Frost as the equivalent of a traditional game launcher (similar to the Steam client). It provides the
user interface for browsing, downloading, and managing your games.

Frost connects to a running **Glacier** server to:

* Retrieve your game library
* Display metadata and artwork
* Start and monitor downloads
* Launch installed games

Glacier handles the backend logic, while Frost provides the desktop experience.
