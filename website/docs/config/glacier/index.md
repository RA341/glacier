# Setup

After installing Glacier, complete the initial setup using the Web UI.

## Access the Web UI

Open the Glacier Web UI in your browser.

## Default Credentials

Use the following credentials to sign in for the first time:

* **Username:**
  ```
  admin
  ```
* **Password:**
  ```
  admin6699
  ```

:::danger
For obvious security reasons, you should change these credentials immediately.

You can update them from the **User Profile** page in the sidebar after logging in.
:::

## Review Server Configuration

1. Navigate to the **Config** page in Glacier.
2. Review all available settings.
3. Update them to match your environment and preferences.

You may also configure settings using environment variables if needed.

## Configure Metadata Provider

Set up a supported metadata provider.

See the [Metadata Setup Guide](metadata.md) for detailed instructions.

## Configure Download Clients

Set up one or more download clients.

See the [Download Clients Guide](download-clients.md) for instructions.

## Configure Indexers

Set up an indexer to enable content discovery.

See the [Indexer Setup Guide](indexers.md) for more information.

## Add Additional Users

To create and manage additional users, refer to the [User Management Guide](users.md).
